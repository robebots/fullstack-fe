# fullstack-fe

A live order book on Hyperliquid's websocket, built for Fullstack's frontend take-home.

https://fullstack-fe-five.vercel.app

`/embed/BTC` shows the widget on its own.

```sh
pnpm install
pnpm dev
```

`pnpm test` runs the unit tests, then the Playwright suite with its perf gates. Run `pnpm exec playwright install chromium` once first.
